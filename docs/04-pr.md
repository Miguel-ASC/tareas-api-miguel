# Pull Request: Validación y corrección de defectos (Bloques 3 y 4)

## Qué cambia

Este PR corrige **5 defectos** donde el código no cumplía con su Javadoc y añade **validación del constructor**:
- Signo invertido en `diasRestantes()` 
- Búsqueda case-sensitive en `buscarPorTitulo()`
- Exclusión de prioridad mínima en `listarPorPrioridadMinima()`
- NPE en `completar(id inexistente)` en lugar de lanzar excepción de dominio
- Constructor acepta títulos vacíos/blanco/null

También incluye **documentación completa**: README reescrito, reporte de validación y ADR de decisión arquitectónica.

## Por qué

Los defectos se detectaron mediante validación sistemática de Javadoc vs implementación durante el taller "Programar con Claude". 
Cada defecto causaba comportamiento incorrecto en operaciones de negocio críticas: cálculo de vencimientos, búsqueda de tareas y gestión de prioridades.

## Cómo se probó

- **19 pruebas unitarias** ejecutadas (JUnit 5), 0 fallos, 0 omitidas
- Metodología TDD: prueba ROJO → código VERDE → commit
- Cada defecto tiene evidencia de fallo antes de corrección (ver reporte)
